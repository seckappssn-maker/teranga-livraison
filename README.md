# Teranga Livraison

App de Seck Apps pour les sociétés de livraison à moto : courses, livreurs, capo de zone, caisse du jour, argent des vendeurs, dépenses des motos.

- `index.html` : le capo, les capos de zone et les livreurs
- `commande.html?c=CODE` : la page où les clients commandent (écrit ou vocal, position GPS)
- Données : Supabase (tables `liv_`)
